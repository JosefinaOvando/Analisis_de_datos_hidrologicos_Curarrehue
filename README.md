# Análisis de Datos Hidrológicos Liucura
(Curso Visualización Datos Medioambientales PUC)

Exploración inicial de series hidrológicas y meteorológicas de la cuenca Rio Liucura En Liucura (9416001), a partir de datos de CAMELS-CL.

## Estructura del repositorio
- datos/: Datos originales y procesados.
- scripts/: Códigos utilizados para análisis.
- figuras/: Gráficos generados durante análisis.
- outputs/: Resultados y tablas finales.

## Variables
El dataset considera series de tiempo diarias de: Caudal/Escorrentía/Precipitación/Temperatura/Evapotranspiración potencial

## Objetivo
Realizar una exploración inicial de los datos, identificando tendencias generales, distribución de las variables y patrones de datos.

## Nota
Los análisis realizados en este repositorio son de carácter demostrativo para el curso.
